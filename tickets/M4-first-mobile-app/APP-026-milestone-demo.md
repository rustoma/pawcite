# APP-026 · Milestone demo: ask from your phone

## Goal
A short demo recording and README section show the full chain working, and version 0.1.0 is tagged.

## Steps
1. Record a short screen video or GIF on your phone: ask a question, get the answer.
2. README: what works today, an architecture diagram, and how to run everything locally (database,
   gateway, API, app).
3. Add the recording to the README.
4. Tag `v0.1.0` and push the tag.
5. In `docs/learning-log.md`, add a "Milestone summary": the five most important things you
   learned in Python and Expo so far.

## Acceptance criteria
